# Stage 9 — JUCE foundation

Local requirements:
- JUCE 9.0.2 at C:\JUCE
- Visual Studio 2026 with MSVC
- CMake

Build:
Open Developer Command Prompt for VS 2026 and run BUILD_JUCE.bat.

This stage only verifies the native JUCE/CMake foundation.
WebView2, React embedding, filesystem scanning, ASIO, MIDI, and playback come next.
