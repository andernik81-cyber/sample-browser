# Agent Rules — Settings

- Работай только над Settings / Preferences.
- Сначала прочитай корневые `AGENTS.md` и `CONTEXT.md`.
- Не переписывай `App.jsx` целиком без необходимости.
- Не удаляй существующее поведение.
- Не добавляй реальную работу с аудиоустройствами.
- Не добавляй MIDI I/O.
- Не добавляй Web Audio API.
- Все будущие native calls обозначай через явный adapter/service слой, если он нужен.
- Settings UI должен быть расширяемым: новые параметры не должны требовать перестройки layout.
- `npm run build` обязателен после изменений.
