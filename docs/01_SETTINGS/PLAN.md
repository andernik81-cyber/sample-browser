# Stage 1 — Settings / Preferences

Добавить только UI-каркас Settings, без JUCE backend.

## Требования

- Кнопка Settings в header.
- Открытие отдельной Settings/Preferences panel/modal.
- Разделы Audio, MIDI, Interface, Shortcuts.
- Controls пока mock/local state.
- UI должен быть готов к последующему связыванию с C++ native functions.
- Не менять существующие размеры/цвета без необходимости.
- Не реализовывать ASIO или MIDI в React.
